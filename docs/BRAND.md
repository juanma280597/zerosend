# Brand direction

## Naming

- Internal codename: **LocalTools**
- Public working name: **ZeroSend**
- Tagline: **Process files. Send nothing.**

`LocalTools` is deliberately not the public recommendation because the name is already heavily used by websites in the same local-file-tools category.

ZeroSend remains a working brand until domain and trademark due diligence are completed.

## Positioning

> Fast browser tools for files you would rather not upload.

The product should feel trustworthy because its behavior is understandable and verifiable, not because it uses absolute marketing claims.

## Tone

- concise
- calm
- technical but accessible
- transparent about limitations
- no fake urgency
- no claims such as “military-grade,” “unhackable,” or “100% anonymous”

## Visual direction

- Near-black primary surface
- Off-white text
- Lime accent (`#B8FF62` initial working value)
- System font stack for speed and fewer third-party requests
- Generous whitespace
- Rounded but restrained components
- No decorative imagery required for the MVP

## Trust language

Preferred:

- “Processed on your device.”
- “Your selected file is not uploaded for processing.”
- “No account required.”

Avoid:

- “The site makes no network requests.” (Ads/assets can make requests.)
- “We cannot access anything on your device.” (Overbroad and unnecessary.)
- “Completely anonymous.”
