# Monetization plan

## Primary model

Google AdSense after the product has:

- a stable public domain,
- useful and working tools,
- substantial publisher-written/reviewed content,
- privacy and terms pages,
- required consent management for applicable regions,
- sufficient navigation and trust signals,
- policy review.

Do not optimize v0.1 around ad density.

## Placement principle

The tool is the main product. Advertising should never look like the upload/select/download controls.

Initial test structure:

```text
Header
H1 + privacy promise
Tool interface
Ad slot
Useful guide / use cases / limitations
Optional second ad slot
FAQ
Related tools
Footer
```

Keep ads away from primary file action buttons and result/download controls.

## Secondary monetization later

Only after traffic exists:

- privacy-friendly affiliate links relevant to workflows,
- optional one-time supporter contribution,
- sponsorship of non-tool editorial content,
- a paid convenience tier only if it provides real additional value without crippling the free tools.

The free core tools should not receive artificial limits simply to manufacture a subscription.
