# Product roadmap

## v0.1 — functional bootstrap

- Image Compressor
- JPG / PNG to WebP
- Image Resizer
- Merge PDF
- Split / extract PDF pages
- Mobile-first responsive UI
- Base technical SEO
- Privacy, terms, about pages
- CI build
- Cloudflare Pages-ready output

## v0.2 — usability and resilience

- Batch image compression/conversion
- Better progress feedback
- PDF thumbnails/reordering improvements
- Split PDF into separate files + local ZIP
- Browser capability/error handling
- Expanded accessibility testing
- Automated tests for pure helpers

## v0.3 — organic acquisition

- Spanish localization
- `hreflang`
- Editorial guides tightly paired with tools
- Search Console
- Core Web Vitals monitoring
- Internal linking system
- Structured related-tools recommendations

## v0.4 — monetization readiness

- AdSense application/readiness review
- Certified CMP for relevant markets
- Production `ads.txt`
- Conservative ad placements
- Privacy-conscious measurement
- Placement experiments based on UX and RPM data

## v0.5 — expansion by validated demand

Candidate tools:

- Crop Image
- Rotate Image
- Remove EXIF Metadata
- Image to PDF
- Remove PDF Pages
- Rotate PDF Pages
- Reorder PDF Pages

Do not ship a tool solely to inflate page count. Prioritize demand, differentiation, local-processing feasibility, and quality.
