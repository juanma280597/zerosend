# International SEO strategy

## Principle

ZeroSend should rank because each page is genuinely useful, fast, specific, and trustworthy—not because thousands of keyword variations are generated.

## Initial English intents

- compress image locally / without upload
- convert jpg to webp without upload
- convert png to webp locally
- resize image privately / in browser
- merge pdf locally / without upload
- split pdf locally / extract pdf pages privately

These are starting intent clusters, not keyword-volume claims. Validate them with Search Console and research before scaling content.

## Page pattern

Every tool page should include:

1. Specific title and H1.
2. Direct value proposition.
3. Working tool above the fold.
4. Local-processing/trust explanation.
5. Short how-to section.
6. Use cases.
7. Supported formats and real limitations.
8. FAQ based on user questions.
9. Relevant related tools.
10. `WebApplication` structured data where appropriate.

## International rollout

1. Launch polished English pages.
2. Add Spanish after the English information architecture is stable.
3. Implement locale-specific URLs and `hreflang` before indexing translated copies.
4. Select further languages from actual impressions, clicks, RPM, and competition.
5. Human-review translated high-intent pages.

## Editorial strategy

Create guides only where they solve an adjacent question and naturally lead to a tool, for example:

- JPG vs PNG vs WebP
- How image compression affects quality
- How to resize images for websites
- How to merge sensitive PDFs without uploading them
- How to extract pages from a PDF locally

Avoid generic AI-generated blog volume.

## Technical SEO

- Static HTML
- Canonical URLs
- XML sitemap
- robots.txt
- Unique metadata
- Semantic headings
- Strong internal links
- Fast mobile rendering
- No required login
- No interstitial before tool use
- Structured data only when it accurately reflects visible functionality
